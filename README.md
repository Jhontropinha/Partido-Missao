# MBL e Partido Missão

Este repositório reúne um site desenvolvido como atividade acadêmica sobre o Movimento Brasil Livre (MBL) e o Partido Missão. O conteúdo apresenta informações históricas, a criação da legenda, propostas políticas, as eleições de 2026 e referências para consulta.

> O projeto tem finalidade educativa e informativa. Não é um site oficial do MBL, do Partido Missão ou de qualquer candidatura.

## Conteúdo do site

O site possui uma página inicial e seis páginas temáticas:

| Arquivo | Assunto |
| --- | --- |
| [Página inicial](html/index.html) | Apresentação do projeto e acesso às seções pelo menu |
| [Página 1](html/pagina1.html) | História e atuação do Movimento Brasil Livre |
| [Página 2](html/pagina2.html) | Criação, registro e identidade visual do Partido Missão |
| [Página 3](html/pagina3.html) | Propostas políticas |
| [Página 4](html/pagina4.html) | Participação do Partido Missão nas eleições de 2026 |
| [Página 5](html/pagina5.html) | Fontes e referências utilizadas no projeto |
| [Página 6](html/pagina6.html) | Checagem de alegações sobre Renan Santos e o Partido Missão |

As páginas compartilham um menu de navegação. A Página 6 tem uma folha de estilo adicional para os cartões e seções de checagem.

- **html/**: páginas e conteúdo do site.
- **css/**: estilos gerais e estilos específicos da página de checagem.

## Como visualizar

Não há etapa de instalação ou compilação. Para abrir o site, abra `html/index.html` no navegador. Você também pode abrir a pasta do projeto no Visual Studio Code e iniciar um servidor local, como a extensão Live Server, usando esse arquivo como página inicial.

Como a página inicial está dentro de `html/`, abra esse arquivo para visualizar o site; a raiz do repositório contém as pastas do projeto.

## Tecnologias

- HTML5 para estruturar as páginas.
- CSS3 para a apresentação visual.
- Links para fontes externas, imagens e materiais de referência.

## Fontes e créditos

As páginas apresentam links para fontes jornalísticas e institucionais, incluindo o Tribunal Superior Eleitoral (TSE), Agência Brasil, Agência Lupa, Aos Fatos, UOL Confere e outras referências citadas no próprio conteúdo. Imagens externas dependem de conexão com a internet e mantêm seus créditos e links de origem junto às páginas.

Consulte as referências diretamente antes de reutilizar informações ou imagens.
